# Vela

**Vela** is an open-source code editor by **Fixnooc**, built on [Code - OSS](https://github.com/microsoft/vscode), the open-source core of Visual Studio Code.

## Building from source

Vela builds the same way as Code - OSS:

```bash
npm install
npm run watch
./scripts/code.sh        # macOS / Linux
.\scripts\code.bat       # Windows
```

See [How to Contribute](https://github.com/microsoft/vscode/wiki/How-to-Contribute) for prerequisites (Node.js, Python, C/C++ build tools).
